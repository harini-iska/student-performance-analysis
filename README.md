
# Student Performance Analysis Using Python

## Project Overview
Student Performance Analysis is a Python-based data analysis project that analyzes students' academic performance using subject-wise marks. It calculates total marks, average marks, grades and identifies the top-performing student.

## Features
- Student marks analysis
- Total and average marks calculation
- Automatic grade calculation
- Pass/Fail status
- Identification of the topper
- Student performance visualization
- Subject-wise performance comparison
- Grade distribution pie chart
- Export results to CSV

## Technologies Used
- Python
- Pandas
- Matplotlib

## Project Structure

```text
student-performance-analysis/
│
├── student_analysis.py
├── student_performance_results.csv
└── README.md
```

## Installation

Install the required libraries:

```bash
python -m pip install pandas matplotlib
```

## How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Run the following command:

```bash
python student_analysis.py
```

## Output
The project generates:
- Student performance bar chart
- Subject-wise average marks chart
- Grade distribution pie chart
- CSV file containing student performance results

## Conclusion
This project demonstrates how Python can be used for data analysis and visualization to understand student academic performance efficiently.
